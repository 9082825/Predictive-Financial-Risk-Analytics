# Predictive-Financial-Risk-Analytics
This is a group project using Data Analysis for Predictive Financial Risk Analytics
This project leverages predictive analytics to strengthen financial decisions by addressing two challenges: loan defaults and transaction fraud. Using Lending Club and Kaggle fraud datasets, we build ML models to estimate default risk and flag fraudulent transactions in real time.
 Defaults/fraud are binary, enabling rigorous modeling with log-loss and ROC-/PR-AUC. Stratified and time-based validation ensures generalization; calibration checks probability quality. Class imbalance is handled via weights/SMOTE. Bootstrapping quantifies uncertainty. Cost-sensitive thresholds translate statistical lift into economic value.
By uncovering patterns in borrower profiles, transaction behavior, and credit factors, the work demonstrates how AI-driven predictions can reduce losses, refine lending strategies, and enhance fraud prevention in an end-to-end solution.
